# 功能需求

> 状态：草稿（2026-08-27 定位修订重写：UI 只读 + Markdown 导出，业务写入唯一入口为 MCP）

## FR-001 MCP 接入与工具集

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 1（2026-08-27 定位修订，MCP 提前至 M1）
- 目标：Agent 成为唯一业务写入方，经统一受控入口访问领域服务
- 描述：系统应提供本地受控 API（仅回环监听、会话令牌鉴权）、mcp-bridge 连接器（stdio↔HTTP 纯转发，负责发现或拉起应用）与 MCP 工具集；Plugin、应用与数据库 Schema 之间执行版本握手，不兼容时返回明确错误。
- 验收依据：
  - MCP 客户端经 bridge 完成初始化并可调用工具；
  - 无效令牌的请求被拒绝；
  - 版本不兼容时调用方收到明确错误而非静默失败。
- 关联：CON-003、CON-007、NFR-005、NFR-009
- 备注：bridge 不持业务数据与用户凭据；候选工具清单见 00 概览"MCP 接入"。

## FR-002 项目管理（MCP）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 2
- 目标：Agent 可以创建和删除项目
- 描述：系统应经 MCP 工具支持项目创建（名称、可选关联仓库路径登记）与删除；删除为级联事务（BR-011），工具参数须显式表达删除确认。
- 验收依据：
  - 创建后项目出现在注册表并可供查询与浏览；
  - 删除后项目及其全部条目、关系、修订不可再访问；
  - 未带确认参数的删除调用被拒绝。
- 关联：BR-011、FR-008
- 备注：关联仓库路径仅为登记，M1 不做仓库内容识别。

## FR-003 条目创建与编辑（MCP）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 2
- 目标：Agent 可以维护条目内容并留下修订记录
- 描述：系统应经 MCP 工具支持条目创建（类型、标题、结构化元数据、Markdown 正文）与编辑；每次内容修改产生新的不可变修订（BR-004），写入携带期望修订号（BR-005）；对已确认条目的编辑按 BR-009 处理状态。
- 验收依据：
  - 新建条目按 BR-001 分配显示编号；
  - 编辑成功返回新修订号；再次读取内容与写入一致；
  - 期望修订号不一致时拒绝并返回冲突信息。
- 关联：FR-004、BR-001、BR-004、BR-005、BR-009
- 备注：条目类型集合为概览 14 种前缀对应类型，全部可创建
  （2026-09-01 用户指令：UI-xxx 升格为第 14 类型，见 03 领域模型 DOM-002 留痕）。

## FR-004 稳定编号分配

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 3
- 目标：条目拥有跨会话稳定、可引用的显示编号
- 描述：系统应在条目创建时按"前缀-序号"分配项目内唯一编号（如 FR-001），内部另持 UUID；编号由领域规则分配，调用方不可自定义序号。
- 验收依据：
  - 同一项目内不存在重复编号；
  - 条目修订、状态变化后编号不变；
  - 已删除或已废弃条目的编号不被复用。
- 关联：BR-001
- 备注：序号按类型独立递增；显示格式与 dev-toolkit 文档体系一致。

## FR-005 条目状态迁移（MCP）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 2；状态机 2026-08-27 访谈确认
- 目标：条目生命周期受控，非法流转被拒绝
- 描述：系统应经 MCP 工具按状态机执行条目状态迁移：草稿 → 评审中 → 已确认；任一非终态 → 已取消；已确认 → 已替代（须指向替代条目）。迁移操作返回成功或明确的拒绝原因。
- 验收依据：
  - 仅允许 BR-002 列出的迁移，其余操作被拒绝并提示原因；
  - 迁移成功后查询与 UI 即时反映新状态；
  - 已替代条目可查询到替代者。
- 关联：BR-002、BR-003、BR-008、BR-009
- 备注：取消迁移须显式确认参数。

## FR-006 关系管理（MCP）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 4；类型集合 2026-08-27 访谈确认
- 目标：条目间的语义关联可由 Agent 建立、查询与移除
- 描述：系统应经 MCP 工具在两个已存在条目间建立有向关系，类型限定五种：派生（derives）、依赖（depends）、满足（satisfies）、追踪（traces）、关联（relates）；支持移除关系。
- 验收依据：
  - 建立后两端条目的关联查询均可见；
  - 重复建立同向同类关系幂等合并或拒绝；
  - 悬空引用与依赖环被拒绝（环返回环上条目序列）。
- 关联：BR-006、BR-007
- 备注：图形化展示在 M2；M1 关系以列表与查询承载。

## FR-007 任务管理（MCP）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 2；任务状态机 2026-08-27 访谈确认
- 目标：Agent 可以创建任务并推进其状态
- 描述：系统应经 MCP 工具支持任务（TASK-* 条目）创建、任务间 depends 依赖建立，以及按状态机迁移：待办 → 进行中 → 待验收 → 完成（含待验收 → 进行中退回；非终态 → 已取消）。
- 验收依据：
  - 仅允许 BR-002 列出的任务迁移，其余被拒绝；
  - 任务的阻塞状态由 BR-010 派生，可被查询；
  - 上游依赖完成后阻塞标记自动消失。
- 关联：BR-002、BR-007、BR-010
- 备注：任务即条目，复用条目编号、修订与关系机制。

## FR-008 项目浏览与切换（UI）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 4（只读定位 2026-08-27 修订）
- 目标：开发者在界面选择要查看的项目
- 描述：系统应在 UI 提供项目列表（名称、关联仓库路径、条目概况），支持打开进入项目查看上下文、关闭返回列表。
- 验收依据：
  - 列表实时反映注册表内容（含 Agent 新建的项目）；
  - 打开后所有查看操作限定在该项目内。
- 关联：FR-002、CON-009
- 备注：UI 不提供创建、删除入口（CON-009）。

## FR-009 条目浏览与详情（UI）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 4
- 目标：开发者阅读条目内容与历史
- 描述：系统应在 UI 提供按类型分组的条目列表与详情视图：结构化元数据、Markdown 正文渲染（只读）、状态与编号展示；详情内含修订历史列表，支持查看任一历史版本完整内容（只读）。
- 验收依据：
  - 条目内容与库中当前修订一致；
  - 历史版本内容只读且与当时保存一致；
  - 数据变化后刷新可见（Agent 写入后 UI 可刷新获得）。
- 关联：BR-004、NFR-008
- 备注：UI 无编辑入口（CON-009）；正文渲染无分栏编辑形态。

## FR-010 关联展开（UI）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 4
- 目标：阅读单个条目时获得其一层关联上下文
- 描述：系统应在条目详情中按关系类型分组显示其直接关联条目（上游与下游、各类型），点击可跳转。
- 验收依据：
  - 对任一条目，可列出全部指向它和它指向的条目及关系类型；
  - 跳转后目标条目详情正常打开。
- 关联：FR-006、FR-013
- 备注：多跳遍历语义见 FR-013 影响定位（遍历方向定义留 03 领域模型）。

## FR-011 任务看板（只读 UI）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 4（只读定位 2026-08-27 修订）
- 目标：开发者纵览任务执行状态与阻塞
- 描述：系统应提供按任务状态分列的看板（待办/进行中/待验收/完成/已取消），只读展示；被未完成依赖阻塞的任务显示阻塞标记与阻塞来源；列内可按编号、标题过滤。
- 验收依据：
  - 看板列与任务状态一致，刷新后反映 Agent 写入的最新状态；
  - 阻塞任务显示"被 XX 阻塞"，阻塞来源完成后标记自动消失；
  - 无任何拖拽或写操作入口。
- 关联：FR-007、BR-010、CON-009
- 备注：状态迁移仅经 MCP（FR-007）。「列内过滤」在 UI 呈现为看板内
  全局单过滤框（同时作用各列），语义不变（2026-08-28 界面设计注记，UI-021）。

## FR-012 关键词搜索（UI）

- 状态：草稿
- 优先级：应该
- 来源：00 概览 M1 范围 4
- 目标：在当前项目内快速定位条目
- 描述：系统应支持按关键词搜索条目，范围包含编号、标题与正文，结果按类型分组，点击跳转详情。
- 验收依据：
  - 输入编号可精确定位；关键词匹配标题或正文的条目出现在结果中；
  - 空结果有明确提示。
- 关联：NFR-002
- 备注：实现方式（FTS 或 LIKE）由架构阶段决定。

## FR-013 影响定位（UI）

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 成功标准
- 目标：设计变化时定位需重新检查的条目与任务
- 描述：系统应对指定条目提供影响视图：沿关系（考虑方向）展开受影响的下游设计条目与 TASK-*，形成"需要重新检查"清单。
- 验收依据：
  - 修改某需求条目后，可列出经派生/满足等关系可达的设计与任务条目；
  - 清单可跳转各条目。
- 关联：FR-010、NFR-002
- 备注：M1 基于关系展开（可多跳）；图形态展示在 M2；参与遍历的关系类型与方向语义留 03 领域模型定义。

## FR-014 Markdown 导出（UI）

- 状态：草稿
- 优先级：必须
- 来源：2026-08-27 定位修订（用户确认导出形式为 Markdown 文档集）
- 目标：开发者获得可归档、可审查的项目文档集
- 描述：系统应支持将项目当前数据导出为 Markdown 文档集（目录或 zip），按类型分组、编号排序，格式与 dev-toolkit 文档体系兼容；导出为只读快照，同数据重复导出结果一致。
- 验收依据：
  - 导出物包含条目正文、状态、修订信息与关系索引；
  - 同一数据两次导出的文件内容与顺序一致；
  - 导出失败时库内数据不受影响。
- 关联：OQ-001（数据库为唯一事实来源）、NFR-004
- 备注：导出不导入（导入与基线快照在 M2）；导出物不是事实来源。

## FR-015 托盘常驻与单实例

- 状态：草稿
- 优先级：必须
- 来源：00 概览 M1 范围 7
- 目标：应用以托盘方式常驻，数据与状态跨会话留存
- 描述：系统应保持单实例；关闭主窗口默认隐藏到托盘；托盘菜单提供显示窗口与退出；再次启动时唤起已有实例。
- 验收依据：
  - 关闭窗口后进程存活、托盘图标可见，数据不丢；
  - 托盘可重新显示窗口且恢复到离开时状态；
  - 二次启动不产生新实例。
- 关联：CON-006
- 备注：托盘常驻同时保障 MCP 通道可用（写入唯一入口依赖应用存活）。

## FR-016 应用设置

- 状态：草稿
- 优先级：应该
- 来源：00 概览 M1 范围 8；2026-08-28 界面设计修订（增加界面语言）
- 目标：用户可调整少量应用行为
- 描述：系统应提供设置界面，M1 包含主题（浅色/深色/跟随系统）、界面语言（中文/英文/跟随系统）与关闭行为（隐藏到托盘/退出），设置持久化并即时生效。
- 验收依据：
  - 修改主题或语言后界面即时切换且重启后保持；
  - 关闭行为切换后，关窗行为随之改变。
- 关联：CON-003、CON-006、CON-009
- 备注：应用设置为非业务数据，是 UI 仅有的持久化写操作。界面语言为
  2026-08-28 界面设计访谈新增（UI-004），条目内容不参与翻译。

## FR-017 恢复上次浏览位置（UI）

- 状态：草稿
- 优先级：应该
- 来源：2026-08-28 界面设计访谈（UI-005）
- 目标：开发者重启应用后回到上次工作位置
- 描述：冷启动时系统应恢复上次关闭时浏览的项目与页面；无上次记录（首次启动）或记录指向已删除项目时，落到项目列表。
- 验收依据：
  - 重启应用后落在上次关闭时所在的项目与页面；
  - 上次项目已被删除时正常落到项目列表，无报错；
  - 托盘唤起保持离开时状态（窗口隐藏非销毁，FR-015 既有行为）。
- 关联：FR-015、FR-016
- 备注：上次位置作为应用设置持久化（last_location），由路由层自动维护，不在设置页暴露。

## FR-018 项目概览视图（UI）

- 状态：草稿
- 优先级：应该
- 来源：2026-08-28 界面设计访谈（UI-011）
- 目标：开发者进入项目即获知项目健康度与活跃度
- 描述：系统应在进入项目后提供概览页（默认落地）：条目与任务的状态统计、按类型分布、最近修订时间线与阻塞任务提醒，全部只读，各模块可跳转对应视图。
- 验收依据：
  - 统计计数与库内当前数据一致，Agent 写入后刷新可见；
  - 最近修订按时间倒序展示操作者（Agent 会话标识或本地用户）与摘要；
  - 阻塞提醒与任务看板阻塞信息一致（同源）。
- 关联：FR-008/009/011、NFR-002
- 备注：新增 IPC 命令 list_recent_revisions 支撑最近修订（INT-001 白名单 +1，2026-08-28）；其余数据复用现有命令。
