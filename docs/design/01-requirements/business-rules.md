# 业务规则

> 状态：草稿（2026-08-27 定位修订：适用入口统一改为 MCP 工具，规则本体不变）

## BR-001 编号唯一且不复用

- 状态：草稿
- 规则：项目内条目显示编号唯一（`UNIQUE(project_id, code)` 语义）；编号一经分配永不复用，即使条目被删除、取消或替代
- 适用条件：所有条目类型；序号按类型前缀独立递增
- 例外：无
- 来源：00 概览核心概念；FR-004
- 关联：FR-004

## BR-002 合法状态迁移白名单

- 状态：草稿
- 规则：状态迁移仅允许下列路径，其余一律拒绝并返回原因——
  条目：草稿→评审中、评审中→已确认、评审中→草稿（退回）、草稿|评审中→已取消、已确认→已替代、已确认→已废弃（显式确认，2026-09-02 新增）；
  任务：待办→进行中、进行中→待验收、待验收→完成、待验收→进行中（退回）、待办|进行中|待验收→已取消
- 适用条件：所有迁移入口（M1 为 MCP 工具，未来其他入口同样受限）
- 例外：终态（已取消、已替代、已废弃、完成）不可再迁移
- 来源：2026-08-27 访谈确认
- 关联：FR-005、FR-007

## BR-003 已确认条目不可物理删除

- 状态：草稿
- 规则：进入已确认状态的条目不允许物理删除，只能取消、废弃（替代）或修订
- 适用条件：条目级删除操作；整项目删除（BR-011）不受此限
- 例外：无
- 来源：00 概览成功标准
- 关联：FR-005

## BR-004 修订不可变且可追溯

- 状态：草稿
- 规则：条目每次内容修改生成新的不可变修订（修订号、时间、修订标题、内容快照）；修订记录不可修改或删除；操作者不入修订记录——变更者审计由结构化操作日志承载（NFR-007；2026-09-03 用户指令调整，远程预留经 CallContext 保留 actor）
- 适用条件：所有内容变更（含状态迁移附带的修订）
- 例外：无
- 来源：00 概览核心概念（Revision）；远程多用户预留
- 关联：FR-003、FR-009

## BR-005 乐观并发

- 状态：草稿
- 规则：条目写入必须携带期望修订号；与当前修订号不一致时拒绝写入并提示冲突，由调用方（MCP 客户端）取得最新内容后重试，系统不自动合并
- 适用条件：所有修改入口
- 例外：无（M1 单 Agent 串行下冲突罕见，机制仍必须存在以约束未来多入口）
- 来源：00 概览安全与一致性原则
- 关联：FR-003、FR-005

## BR-006 悬空引用拒绝

- 状态：草稿
- 规则：关系的两端条目必须存在；指向不存在条目的关系被拒绝创建，条目删除时其关联关系一并处理（级联删除或阻止删除）
- 适用条件：关系创建与条目删除
- 例外：无
- 来源：00 概览成功标准
- 关联：FR-006

## BR-007 依赖不成环

- 状态：草稿
- 规则：depends 关系沿有向边不允许形成环（含任务间依赖）；成环的添加操作被拒绝并指出环上条目
- 适用条件：depends 类型；其他类型不参与环检测
- 例外：无
- 来源：00 概览成功标准
- 关联：FR-006、FR-007

## BR-008 终态操作的显式语义

- 状态：草稿
- 规则：迁移到已替代必须同时指定替代者条目（形成替代关系）；迁移到已取消或已废弃需显式确认；已替代条目必须可查询到替代者
- 适用条件：条目终态迁移
- 例外：无
- 来源：00 概览"取消、废弃或替代"
- 关联：FR-005
- 备注：替代关系的存储形态（条目字段或关系实例）留 03 领域模型决定。

## BR-009 已确认条目编辑后退回评审

- 状态：已确认（2026-08-27 随 02 用例 UC-004 定稿）
- 规则：对已确认条目的内容修改产生新修订，同时状态回到评审中（须重新确认），保持"已确认 = 当前内容已被审阅"的语义
- 适用条件：内容编辑；纯元数据修改是否触发退回待细化
- 例外：无
- 来源：2026-08-27 访谈拟定，同日随用例基线定稿
- 关联：FR-003、FR-005、UC-004

## BR-010 阻塞为派生属性

- 状态：草稿
- 规则：任务的阻塞状态不是独立状态，而是由"存在未完成的 depends 上游任务"派生；上游全部完成后阻塞标记自动消失
- 适用条件：任务看板与详情展示、MCP 查询
- 例外：无
- 来源：2026-08-27 访谈确认（避免状态机与依赖规则双轨）
- 关联：FR-007、FR-011

## BR-011 项目删除为级联事务

- 状态：草稿
- 规则：删除项目在单个事务中级联删除该项目的全部条目、关系与修订；删除后编号空间一并废弃；删除须显式确认（M1 入口为 MCP 工具，确认语义以工具参数承载）
- 适用条件：项目管理入口
- 例外：无
- 来源：FR-002
- 关联：FR-002、BR-003
