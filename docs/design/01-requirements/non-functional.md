# 非功能需求

> 状态：草稿（2026-08-27 定位修订：NFR-005 改写为回环 API 安全，新增 NFR-009）

## NFR-001 数据可靠性

- 状态：草稿
- 类别：可靠性
- 适用范围：全局
- 驱动场景：编辑过程中进程崩溃、断电或被强制结束
- 指标与阈值：已成功保存（事务提交返回）的数据零丢失；崩溃重启后数据库可打开且处于一致状态，最坏丢失未提交的变更
- 验证方式：集成测试模拟提交中断（注入失败）；WAL 模式下强杀进程后重启校验
- 来源：00 概览安全与一致性原则
- 关联：BR-004、BR-005、NFR-009

## NFR-002 数据规模与响应

- 状态：草稿
- 类别：性能
- 适用范围：列表、看板、关联展开、搜索、MCP 查询
- 驱动场景：单项目累计条目与修订增长
- 指标与阈值：1 万条目、5 万修订规模内，列表加载、看板渲染、关联展开、搜索与 MCP 条目读取的可感知完成时间 ≤ 1 秒
- 验证方式：构造规模数据的自动化测试计时
- 来源：单开发者多项目长期使用的合理上界
- 关联：FR-010、FR-011、FR-012

## NFR-003 启动与唤回性能

- 状态：草稿
- 类别：性能
- 适用范围：应用启动、托盘恢复、bridge 拉起
- 驱动场景：冷启动、关闭窗口后从托盘再次打开、MCP 首次连接拉起应用
- 指标与阈值：冷启动到主窗口可交互 ≤ 3 秒；托盘隐藏后唤回到可交互 ≤ 0.5 秒（普通消费级开发机）
- 验证方式：手动计时 + 启动性能日志
- 来源：托盘常驻产品形态
- 关联：FR-015
- 备注：bridge 拉起应用的就绪时限在 05 详细设计定义。

## NFR-004 可恢复性

- 状态：草稿
- 类别：可靠性
- 适用范围：M1（确定性快照到位前）
- 驱动场景：用户需要备份或迁移数据
- 指标与阈值：数据库文件级备份（复制或 VACUUM INTO）可完整恢复全部项目数据；恢复操作有文档说明
- 验证方式：备份→清空→恢复→数据一致校验
- 来源：OQ-001 快照延迟到 M2 的补偿措施
- 关联：CON-003、FR-014

## NFR-005 本地安全

- 状态：草稿
- 类别：安全
- 适用范围：M1（含本地 MCP API）
- 驱动场景：多用户操作系统环境；本机其他进程尝试访问 API
- 指标与阈值：数据目录与数据库文件仅当前用户可读写；本地 API 仅绑定回环地址，每会话轮换随机令牌（bridge.json 仅当前用户可读）；除该回环端口外无任何网络监听
- 验证方式：文件权限检查；端口扫描确认仅回环监听；无效令牌请求被拒绝的测试
- 来源：00 概览安全原则（2026-08-27 修订：MCP 提前，回环 API 随 M1 交付）
- 关联：CON-003、FR-001

## NFR-006 升级兼容

- 状态：草稿
- 类别：可维护性
- 适用范围：应用版本升级
- 驱动场景：应用更新后打开旧版本数据
- 指标与阈值：Schema 迁移自动执行且不丢数据；不支持的降级（新库配旧应用）给出明确错误而非静默损坏
- 验证方式：迁移测试覆盖每个历史版本库
- 来源：单数据文件长期演化的必然要求
- 关联：CON-003、FR-001

## NFR-007 可观测性

- 状态：草稿
- 类别：可观测性
- 适用范围：全局
- 驱动场景：用户或 Agent 报告问题需要诊断
- 指标与阈值：日志写入 `~/.relayharbor/logs/`，含错误、迁移记录、关键操作摘要与 MCP 工具调用记录（会话、工具、结果概要）；日志可按会话区分且自动轮转
- 验证方式：功能测试检查日志产出
- 来源：Agent 参与开发与写入，问题定位依赖可读日志
- 关联：CON-003

## NFR-008 界面一致性

- 状态：草稿
- 类别：可用性
- 适用范围：全局 UI
- 驱动场景：日常长时间使用
- 指标与阈值：全部界面基于 Fluent UI v9 组件与设计令牌；浅色/深色主题完整覆盖无遗漏页面；高频查看操作（搜索、跳转、导出）可键盘完成
- 验证方式：UI 走查 + 主题切换全覆盖检查
- 来源：技术选型（CON-004）
- 关联：FR-009、FR-016

## NFR-009 写入原子性与可判定失败

- 状态：草稿
- 类别：一致性
- 适用范围：MCP 写入工具
- 驱动场景：工具调用中途失败（校验失败、进程中断）
- 指标与阈值：多步变更以 ChangeSet 单事务原子提交：要么全部生效并返回新修订号，要么全部不生效并返回明确失败原因；不存在半写状态
- 验证方式：集成测试注入失败点，校验库内无部分变更
- 来源：MCP 为唯一写入方（2026-08-27 定位修订）
- 关联：BR-004、BR-005、FR-003
