## 需求范围与版本目标

本阶段需求对应 **M1（Agent 写入平面 + 只读 UI）**：业务写入唯一入口是
MCP（Agent 创建/编辑条目、迁移状态、维护关系、管理任务），桌面界面只读
浏览（条目、关联、看板、修订历史、影响定位）并导出 Markdown 文档集，数据
可靠留存。M2（基线确认流程与变更集 UI、Markdown/JSON 确定性导入与快照、
关系图可视化）的需求在 M1 交付后进入本阶段补充，当前仅保留概览级描述，
不占编号。M2 范围内已有决策记录在约束与业务规则中，避免将来返工。

2026-08-27 定位修订说明：原稿按"UI 管理平面（M1）+ MCP（M2）"编写，经
用户确认改为"UI 只读与导出、MCP 写入提前至 M1"，全部条目已按新定位重写。

## 优先级定义

- **必须**：M1 交付缺失即不满足概览成功标准；
- **应该**：M1 内尽量交付，可延至 M1 收尾，不阻塞 M2；
- **可以**：体验增强，允许顺延；
- **暂不**：M2 及以后，不占用当前实现排期。

## 关键非功能驱动因素

对架构影响最大的四项：NFR-001 数据可靠性（崩溃不丢已提交数据，决定 WAL
与事务边界）、NFR-005 本地安全（回环 + 会话令牌，决定本地 API 形态与
bridge 机制）、NFR-006 升级兼容（Schema 迁移向前兼容，决定迁移机制）、
NFR-009 写入原子性（MCP 为唯一写入方，工具失败不得留半写状态）。
