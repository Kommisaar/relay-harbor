# UC-006 建立或移除关系

> 状态：草稿
> 关联：FR-006、BR-006、BR-007、NFR-002

## 目标

Agent 在两个已存在条目间建立有向语义关系，或移除既有关系；系统保证引用
完整与依赖无环。

## 参与者

- 主要参与者：ACT-002 设计与规划 Agent
- 支持参与者：无

## 触发

Agent 调用关系工具：建立（源条目、目标条目、类型）或移除（关系标识 /
两端 + 类型）。

## 前置条件

- MCP 会话与令牌有效；
- 项目存在。

## 最小保证

- 失败时关系集合不变；
- 拒绝原因明确（悬空引用 / 成环 / 类型非法 / 重复）。

## 成功保证

- 关系建立后，两端条目的关联查询均可见该关系（含方向与类型）；
- 移除后两端视图同步不再显示；
- depends 关系集合始终无环（BR-007）。

## 主流程

1. Agent 提交建立请求（源、目标、类型 ∈ {derives, depends, satisfies, traces, relates}）；
2. 系统校验会话与项目归属；
3. 系统校验两端条目存在且非悬空（BR-006）；
4. 系统校验同向同类关系不存在（重复则幂等返回已存在）；
5. 若类型为 depends：执行环检测——沿既有 depends 边判断加入该边后是否
   成环（BR-007）；
6. 系统在单个事务内写入关系；
7. 系统返回关系标识；两端关联查询立即可见。

## 备选流程

### A1 悬空引用

任一端条目不存在：拒绝并指明缺失端（BR-006）。

### A2 依赖成环

第 5 步检测到环：拒绝，返回环上条目序列（按遍历顺序），调用方据此调整
（BR-007）。

### A3 重复关系

同向同类关系已存在：幂等处理，返回已存在的关系标识，不报错。

### A4 类型或方向非法

类型不在五种之列，或该类型对方向有约束（如 derives 的方向语义，03 领域
模型定义）：拒绝并说明。

## 异常流程

### E1 并发删除端点

事务提交前另一入口删除了端点条目：事务内校验失败回滚，返回悬空错误。

### E2 事务失败

写入中断：关系集合回滚到调用前（NFR-009）。

## 业务规则

- BR-006：悬空引用拒绝；
- BR-007：depends 不成环，拒绝时指出环上条目。

## 非功能要求

- NFR-002：环检测与关系查询在目标数据规模下 ≤ 1 秒。

## 开放问题

- 关系方向语义已在 03 领域模型定稿：统一读作"A 对 B 做某事"（动者在前，
  A derives B = A 派生自 B 等，见 DOM-003）；反向对（A rel B 且 B rel A）
  不禁止，由 Agent 自律。
