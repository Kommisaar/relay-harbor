# UC-016 导出 Markdown 文档集

> 状态：草稿
> 关联：FR-014、OQ-001、NFR-004

## 目标

开发者将项目当前数据导出为与 dev-toolkit 文档体系兼容的 Markdown 文档集，
用于归档、审查或库外阅读。

## 参与者

- 主要参与者：ACT-001 开发者
- 支持参与者：ACT-003 系统环境（导出目标路径的文件系统）

## 触发

开发者在项目列表卡片点击「导出」，在弹出框中选择参数并执行
（2026-08-28 用户指令：导出由独立页面改为卡片弹出框，ui/pages/export.md）。

## 前置条件

- 应用已打开该项目（UC-010）；
- 导出目标路径存在且当前用户可写。

## 最小保证

- 导出为纯读取操作：任何失败不改动库内数据；
- 失败时明确提示（原因与已完成的部分），不留误导性的"成功"产物。

## 成功保证

- 导出物包含项目全部（或所选范围）条目：正文、状态、修订信息与关系索引；
- 目录结构与文件内容按固定规则生成：同数据两次导出结果一致（确定性）；
- 格式与 dev-toolkit 文档体系兼容（编号、类型分组、Markdown 结构）。

## 主流程

1. 开发者选择导出（范围：整项目 / 按类型筛选）与目标路径（目录或 zip）；
2. 系统从数据库读取当前数据（条目、状态、修订、关系）；
3. 系统按固定结构渲染 Markdown：类型分组、编号排序、每条目一个文档、
   附关系索引与项目信息；
4. 系统写入目标位置；
5. 系统提示完成并展示导出位置。

## 备选流程

### A1 目标路径不可写

第 4 步写入失败：提示原因（权限 / 磁盘满 / 路径不存在），不产生半成品
标记；已写入的部分在提示中说明。

### A2 项目为空

无任何条目：提示"项目为空"并中止，不产生只含骨架的导出物（或经确认后
导出骨架，默认中止）。

### A3 范围筛选无匹配

所选类型无条目：提示并中止，或经确认导出其余类型。

## 异常流程

### E1 读取中断

数据库读取失败：中止导出，提示错误；库内数据不受影响。

## 业务规则

- 无状态变更；导出物是只读快照，不作为事实来源（OQ-001）。

## 非功能要求

- NFR-004：作为文件级备份的补充（完整备份仍以数据库文件为准）；
- NFR-002：导出在目标数据规模下可完成，不阻塞界面（进度提示）。

## 开放问题

- 已在 05 详细设计定案（api-contracts.md INT-006、modules/export.md）：
  每类型一目录、每条目一文件的确定性结构；修订历史默认仅当前修订 +
  历史摘要；目标已存在即拒绝；异步执行 + 进度事件。
