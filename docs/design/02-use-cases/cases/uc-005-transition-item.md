# UC-005 迁移条目状态

> 状态：草稿
> 关联：FR-005、BR-002、BR-003、BR-008

## 目标

Agent 推进条目生命周期（提交评审、确认、退回、取消、替代、废弃），系统保证只有
白名单内的迁移发生。

## 参与者

- 主要参与者：ACT-002 设计与规划 Agent
- 支持参与者：无

## 触发

Agent 调用状态迁移工具（`transition_item`），携带条目标识、目标状态与
终态所需参数（替代者标识 / 取消确认标志）。

## 前置条件

- MCP 会话与令牌有效；
- 项目与目标条目存在；
- 期望修订号随调用携带（BR-005，机制同 UC-004）。

## 最小保证

- 拒绝时条目状态与修订不变；
- 每次拒绝都携带可读原因（哪条规则、当前状态、允许的目标状态）。

## 成功保证

- 条目状态变更为目标状态，迁移记录于修订（BR-004）；
- 已取消、已废弃条目保持可查询；已替代条目可查询到替代者（BR-008）；
- 已确认条目从未被物理删除（BR-003）。

## 主流程

1. Agent 提交迁移请求（条目、目标状态、参数）；
2. 系统校验会话与项目归属；
3. 系统按 BR-002 白名单校验"当前状态 → 目标状态"合法；
4. 系统校验终态参数（BR-008）：
   - 目标为已替代：替代者条目必须存在、非自身、非终态；
   - 目标为已取消或已废弃：确认参数必须显式携带；
5. 系统在单个事务内变更状态并追加修订记录（含迁移前后状态）；
6. 系统返回新状态与修订号。

## 备选流程

### A1 迁移不在白名单

第 3 步校验失败（如已确认 → 草稿）：拒绝，返回当前状态与允许的目标状态
列表。

### A2 替代者无效

替代者不存在、指向自身或本身处于终态：拒绝并说明原因。

### A3 取消未带确认参数

目标为已取消但调用未显式确认：拒绝，要求补全参数后重试。

### A4 评审退回

评审中 → 草稿为白名单内迁移，正常执行；修订记录标注"评审退回"。

## 异常流程

### E1 事务失败

迁移事务中断：状态与修订均回滚，返回明确错误（NFR-009）。

## 业务规则

- BR-002：迁移白名单（条目：草稿→评审中→已确认；评审中→草稿；
  草稿|评审中→已取消；已确认→已替代）；
- BR-003：已确认条目不可物理删除；
- BR-004：迁移附修订记录；
- BR-008：终态显式语义。

## 非功能要求

- NFR-009：原子提交或明确失败。

## 开放问题

- 替代关系存储形态已在 03 领域模型定稿：条目字段 superseded_by（DOM-002、
  INV-006），不作为第六种关系。
