# 参与者

> 状态：草稿

## ACT-001 开发者

- 类型：主要参与者
- 目标：浏览与审阅项目的设计资产（条目、关系、任务、修订），定位变更影响，导出 Markdown 文档集
- 权限特征：业务数据只读；可调整应用设置（非业务数据）
- 备注：M1 唯一的人类参与者；不在 UI 执行任何业务写操作（CON-009）
- 关联用例：UC-010～UC-018

## ACT-002 设计与规划 Agent

- 类型：主要参与者
- 目标：经 MCP 维护项目的设计资产——创建/编辑条目、执行状态迁移、维护关系、管理任务，并按稳定编号查询上下文
- 权限特征：唯一业务写入方（经本地受控 API + 会话令牌）；受状态机、编号、环检测等领域规则约束
- 备注：以 MCP 客户端形态接入（dev-toolkit Plugin 经 mcp-bridge）；执行 Agent（按 TASK 回写状态）未来复用同一入口
- 关联用例：UC-001～UC-009

## ACT-003 系统环境

- 类型：支持参与者
- 目标：提供托盘集成、单实例互斥、文件系统（数据目录、bridge.json、导出目标）与回环网络环境
- 权限特征：无业务语义；故障（文件权限、端口占用、路径不可写）表现为明确错误
- 备注：Windows 外壳优先（OQ-005）
- 关联用例：UC-009、UC-016、UC-017
