# 设置页

> 状态：待确认
> 路由：`/settings`（第一层活动栏「设置」入口）
> 关联：UI-024、FR-016/017、CON-003/006/009、UC-018、CMP-001

## 布局（UI-024）

单页两张分组卡片（设置项少，无子导航）：

```text
设置
┌ 外观 ──────────────────────
│ 主题   [跟随系统 ▾]   （跟随系统/浅色/深色）
│ 语言   [跟随系统 ▾]   （跟随系统/中文/英文）
├ 行为 ──────────────────────
│ 关闭窗口时 [隐藏到托盘 ▾] （隐藏到托盘/退出）
└────────────────────────────
```

## 数据

`get_settings` / `set_settings`（应用设置，后端 settings.json；UI 仅有
的持久化写操作，FR-016 备注）。`last_location`（FR-017）由路由层自动
维护，不在设置页暴露。

## 交互

- 每项即时生效并持久化（无「保存」按钮）；
- 主题/语言切换经 AppProviders 全局响应（app-shell.md）；
- 关闭行为切换后，关窗行为随之改变（FR-016 验收）。

## 状态与边界

设置读取失败：错误组件 + 重试（应用仍可用默认值运行）。

## 测试要点

修改即时生效且重启保持（主题/语言/关闭行为三项验收）；设置页无任何
业务数据入口。
