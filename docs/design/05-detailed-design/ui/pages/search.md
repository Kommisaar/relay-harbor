# 搜索页

> 状态：待确认
> 路由：`/projects/:id/search`
> 关联：UI-022、FR-012、UC-014、CMP-001

## 布局（UI-022）

- 页内搜索框（进入自动聚焦）+ 回车触发查询；无全局快捷入口、无即时
  下拉（M1 零投机，UI-022）；
- 结果：手风琴分组（与条目浏览一致，UI-012/013），按类型分组，组内
  标准行 = 编号 + 标题 + 状态徽章 + 修订号 + 更新时间 + 正文命中
  摘要片段（命中词高亮，实现自选）；
- 匹配范围：编号（精确/前缀）、标题、正文（search_items 契约）。

```text
搜索            [关键词… ⏎]
┌ FR 功能需求 (2) ───────────────── ▾
│ FR-012  导出…  [已确认] r4
│   …匹配正文片段…
└ TASK 任务 (1) ─────────────────── ▸
```

## 数据

`search_items(project_id, q)` → `["projects", id, "search", q]`。

## 交互

- 点击结果行 → 条目详情；
- 空关键词不触发查询。

## 状态与边界

- 无结果：「未找到匹配 XX 的条目」+ 建议（FR-012 验收要求，UI-031）；
- 加载：结果骨架；错误：统一组件 + 重试。

## 测试要点

编号精确命中；标题/正文关键词命中；空结果提示文案。
