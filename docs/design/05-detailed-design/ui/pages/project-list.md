# 项目列表页

> 状态：待确认
> 路由：`/projects`
> 关联：UI-010、FR-008、UC-010、CMP-001

## 布局

未选项目时第二层导航「项目」的落地内容，内容区整页呈现：

- **双形态可切换**（右上切换控件，记入 Zustand「视图模式」UI 态）：
  - 列表行（默认）：每行 = 项目名 + 仓库路径（等宽字体，无则省略）+
    条目/任务计数摘要 + 最近更新时间 + 紧凑统计行（条目已确认率 / 任务完成率
    微型分段条）；点击进入项目（默认落概览页）；
  - 卡片网格：每卡 = 项目名 + 更新时间 + 仓库路径次要行 + 统计区块
    （条目/任务状态分段条 + 比率文案 + 前 4 类型计数 chip 与「+N」溢出）
    + 头部右侧「导出」按钮（弹出框表单，见 [export](export.md)）。
- **项目卡片统计**（2026-08-28 增补：用户要求卡片呈现更多信息与图表）：
  - 数据源：`get_project_state`（query key `["projects", id, "state"]`，与概览页
    共享缓存），列表页不新增 IPC 命令；
  - 分段条按 UI-030 状态语义色取色，但走 Fluent 主题令牌（共享组件
    `StatusMeter`）而非 AntV 调色板——令牌随明暗主题自动切换且与状态徽章语义
    一致，并避免每卡挂一个 canvas；完整图表仍保留在概览页（UI-011），
    卡片只做微型摘要（实现偏差注记：patterns「图表用 @ant-design/charts」
    针对页面级图表，卡片微型统计不在此列）；
  - 统计查询加载中骨架占位防跳动；失败降级为占位文案，不阻塞进入项目；
  - 0 条目 / 0 任务不计算比率（不除零），显示「暂无」提示。
- 工具条：关键词过滤框（前端本地过滤项目名即可，项目数量级小）。

```text
项目                                    [列表|卡片] [过滤…]
┌────────────────────────────────────────────┐
│ ● relay-harbor                             │
│   D:\projects\relay-harbor                 │
│   条目 156 · 任务 12 · 更新 2 分钟前        │
├────────────────────────────────────────────┤
│ ○ zhsppy-extract  …                        │
└────────────────────────────────────────────┘
```

## 数据

`list_projects`（含名称、仓库路径、条目概况计数）→ query key `["projects"]`；
卡片统计区块另取 `get_project_state`（`["projects", id, "state"]`，与概览页共享缓存）。

## 交互

- 点击项目 → `/projects/:id/`（概览），当前项目 id 写 Zustand；
- 卡片「导出」按钮 → 弹出导出表单（Popover），弹层内点击不冒泡到
  卡片（不触发进入项目）；
- 无创建/删除/编辑入口（CON-009）；列表实时反映 Agent 新建项目
  （data-changed 失效 + 聚焦兜底）。

## 状态与边界

- 空：引导空态「项目由 Agent 经 MCP 创建」（UI-031）；
- 加载：骨架行/骨架卡片；错误：统一错误组件 + 重试。

## 测试要点

形态切换与记忆；点击进入后导航态切换为已选项目；空态呈现；
卡片统计骨架与降级文案；0 条目 / 0 任务不除零；明暗主题下分段条语义色一致。
