# 项目概览页

> 状态：待确认
> 路由：`/projects/:id/`（index，进入项目默认落地页）
> 关联：UI-011、FR-018、FR-008/009/011、UC-010、CMP-001

## 布局

单栏分区（自上而下），四个模块统一卡片式（Fluent `Card`；2026-08-28
实现期修订：初版仅状态统计为卡片，用户确认其余三区同改卡片式）：

1. **状态统计卡片行**：条目按状态计数（草稿/评审中/已确认/终态）+
   任务按状态计数（待办/进行中/待验收/完成/已取消），双卡片并排；
   每卡 = 状态环形图（AntV `Pie`+`innerRadius`，走 AntV 主题默认色组
   category10，随明暗主题自动适配，2026-08-28 用户选型）+ 环心总量 +
   下方计数清单（图例徽章取同一默认色组，与扇区一一对应），
   点击任务分组跳看板；
2. **类型分布卡片**：14 种类型的条目计数竖向柱状图（AntV `Column`，
   各类型按主题默认色组 category10 依次取色，x 轴为类型代码，
   底部中文名原生图例（2026-08-28 用户要求添加；点击图例项隐藏/显示
   对应柱），悬停显示中文名与计数；2026-08-28 用户确认移除柱顶数值
   标注，数量改由 tooltip 查看，图表高度随图例增至 280）；
   图表选型 2026-08-28 用户确认采用 @ant-design/charts（@ant-design/graphs
   预准入供 M2 关系图，替代 @xyflow）；
3. **最近修订时间线卡片**：最近 N 条（默认 10）跨条目修订，按时间倒序，
   每条 = 编号 + 标题 + 修订号 + 操作者（Agent 会话标识或本地用户）+
   摘要 + 相对时间，点击跳条目详情；
4. **阻塞提醒卡片**：当前被阻塞任务计数 + 清单（任务编号 + 阻塞来源编号），
   点击跳看板对应卡片。

## 数据

- `get_project_state`（各类型/状态计数）→ `["projects", id, "state"]`
  （统计卡片 + 类型分布）；
- `get_task_board` → `["projects", id, "task-board"]`（阻塞提醒；
  与看板同源，保证一致）；
- `list_recent_revisions`（**新增命令**，INT-001 白名单 13→14）：
  参数 `project_id, limit`，返回跨条目修订摘要（display_code、标题、
  revision_no、actor、summary、changed_at，changed_at 倒序）→
  `["projects", id, "revisions-recent"]`。

## 交互

全部只读；各模块条目均可跳转（详情页/看板/对应类型条目列表锚点）。

## 状态与边界

- 空项目：统计全零 + 引导空态文案（条目由 Agent 写入）；
- 无阻塞：显示「无阻塞任务」正向提示，不隐藏区块。

## 测试要点

统计与库内一致；最近修订倒序与 actor 呈现；阻塞数与看板一致。
