## 布局

单栏分区（自上而下），四个模块统一卡片式（Fluent `Card`；2026-08-28
实现期修订：初版仅状态统计为卡片，用户确认其余三区同改卡片式）：

1. **状态统计卡片行**：条目按状态计数（草稿/评审中/已确认/终态）+
   任务按状态计数（待办/进行中/待验收/完成/已取消），双卡片并排；
   每卡 = 状态环形图（AntV `Pie`+`innerRadius`，走 AntV 主题默认色组
   category10，随明暗主题自动适配，2026-08-28 用户选型）+ 环心总量 +
   下方计数清单（图例徽章取同一默认色组，与扇区一一对应），
   点击任务分组跳看板；
2. **图表卡片行（双卡并排，2026-09-02 用户指令：类型分布只占一半，
   另一栏新增活动图）**：
   - **类型分布卡片**：15 种类型的条目计数竖向柱状图（AntV `Column`，
     各类型按主题默认色组 category10 依次取色，x 轴为类型代码，
     底部中文名原生图例（2026-08-28 用户要求添加；点击图例项隐藏/显示
     对应柱），悬停显示中文名与计数；2026-08-28 用户确认移除柱顶数值
     标注，数量改由 tooltip 查看，图表高度随图例增至 280）；
     图表选型 2026-08-28 用户确认采用 @ant-design/charts（@ant-design/graphs
     预准入供 M2 关系图，替代 @xyflow）；
   - **活动图卡片**：逐日修订计数日历网格（GitHub 贡献图形态，
     2026-09-02 用户指令新增；同日多次指令迭代：26 周收窄 16 周并
     加大格子、命名自「修订热力图」改「活动图」并移除月份/星期
     标注、自适应撑满）——格 28px 固定、列距 31px，显示周数按卡片
     可容列数实时计算（ResizeObserver 随窗口缩放重算，4~26 周钳制，
     26 周 = 数据全量 182 天），画布宽 = 实测列网格宽（自适应撑满
     卡片至下一整列）；周一为首行，窗口按末日所在周周一整周对齐
     回推、头部跨周散日舍弃；底色按当日修订数分 5 档（0 档中性
     浅底、1~4 档品牌色透明度递增）随明暗主题切换；悬停
     tooltip 与其他图表统一（2026-09-02 用户指令）：共用
     ChartTooltip 的 tooltipRender——色点（缺省取格子档位色）+
     日期 + 加粗「N 修订」（i18n heatmapDayTooltip → revisionCount）；
     无图例、无坐标轴（2026-09-02 用户指令
     移除「少 → 多」图例；同日试用 AntV 原生色带图例与日期范围
     副标题后均被用户否决移除，维持纯网格）。进场动画逐格
     `zoomIn`（2026-09-02 用户指定，update/exit 默认）。实现：AntV `Heatmap`
     （`mark="cell"` + threshold 五档色阶，坐标轴全隐）。G2 v5
     无现成日历布局变换——整周对齐与周/星期分列在数据侧预计算；
     canvas 无 CSS 变量，色值经 Fluent 主题对象取具体值。
     2026-09-02 用户指出 AntV 有热力图并确认改用，消除早前
     「Griffel 网格手绘」偏差（见 design README 留痕）；数据同源
     get_project_state 扩展字段
     `revisions_by_day`（近 182 天逐日计数，UI 按卡片宽度截取
     最近 N 周渲染，见 api-contracts）。
3. **最近修订时间线卡片**（独占一栏）：最近 N 条（默认 10）跨条目修订，按时间倒序，
   每条 = 编号 + 标题 + 修订号 + 摘要 + 相对时间（操作者列随修订模型

  `["projects", id, "state"]`（统计卡片 + 类型分布 + 活动图）；

  2026-09-03 用户指令移除）→
  `["projects", id, "revisions-recent"]`。
