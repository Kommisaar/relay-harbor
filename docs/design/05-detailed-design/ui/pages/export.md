## 入口与布局

项目列表卡片网格：每卡头部右侧「导出」图标按钮（次级外观，
`title`/aria =「导出 Markdown」），点击弹出 Popover 表单
（约 360px 宽，内容超高时滚动）：

1. **范围**：单选「整项目 / 按类型」；按类型时 14 类多选（默认全选）；
2. **形式**：单选「目录 / zip」；
3. **目标路径**：路径输入 + 提示「目标已存在将拒绝覆盖」（INT-006
   既有语义；系统目录选择器联调时接 Tauri dialog）；
4. **导出按钮**：提交后执行态——禁用 + 进度条（异步进度，NFR-002
   不阻塞界面）；
5. **结果条**：成功 = 完成摘要 + 「打开目录」动作；失败 = 原因
   （UC-016 A1/E1），无误导性成功产物。

原 UI-023 表单结构逐项沿用，仅承载由整页改为弹出框。

## 数据

`export_markdown(project_id, scope?, target_path)`（INT-006）+ 导出
进度事件；目录结构确定性规则见 modules/export.md（本文不重复）。
实现注记：弹出框为共享组件 `components/ExportPopover`（项目列表
feature 消费）——feature 间禁止互相引用，原 `features/export` 目录随
页面一并移除。

## 交互

- 弹出层内一切点击不冒泡到卡片（卡片点击 = 进入项目）；
- 写目标是文件系统快照，非业务库（OQ-001：导出物不是事实来源）——
  CON-009 只读边界的既有例外（patterns.md）不变；
- 关闭弹出框即放弃本次表单；执行中关闭不中断导出，重开显示当前进度。

## 状态与边界

- 项目为空：提示并中止（UC-016 A2 默认中止）；
- 范围筛选无匹配：提示（A3）；
- 目标不可写：失败结果条呈现原因（A1）。

## 测试要点

表单参数与 export_markdown 契约一致；进度事件驱动进度条；失败路径
提示完整；弹出层点击不触发卡片跳转；旧路由 `/export`、
`/projects/:id/export` 访问回落项目列表（通配路由兜底）。
