1. **头部**：面包屑（项目 / 类型组 / 返回列表）+ 编号（等宽大字）+
   标题 + 状态徽章 + 元数据摘要 chip（结构化 metadata 键值对：优先级、
   备注等）+ 修订元信息两枚 chip（2026-09-04 二改：版本身份

2. **正文**：Markdown 渲染（react-markdown，只读，无分栏编辑形态——
   CON-009）；
3. **详情面板浮动胶囊**（2026-09-03 用户指令由「修订历史」胶囊扩为
   三分区面板，壳层见 patterns.md「浮动胶囊面板」）：单胶囊 fixed
   悬浮视口右上（同日定位修订：距右缘 24px、顶距 24px；「详情面板」+
   计数徽标：查看历史版时显 rN，否则显
   修订数；查看历史版时胶囊呈选中底色），面板无名称标题行（同日二改：
   收起按钮改居首分区小节标题行右侧）；三分区以全宽 hairline 分隔、
   小节标题与内容最左元素统一左缘、内容超高内部滚动；小节标题区可
   点击折叠/展开对应分区（2026-09-03 用户指令：标题后 chevron 旋转
   指示 + 高度过渡；折叠分区 ≠ 收起面板，状态本地不持久化）：
   - **修订历史**（FR-009/UI-017）：修订号 + 摘要 + 时间 + 标题
     （RadioGroup 时间线形态，见 patterns.md）；点选版本切换正文、
     点当前版回到当前；正文默认显示快照全文，由分区标题行右缘的
     「与上一版对比」开关（2026-09-03 用户指令，收起按钮左侧图标

   - **关联**（FR-010）：按关系类型分组（derives/depends/satisfies/

## 数据

- `get_item_detail` → `["projects", id, "item", code]`；
- `get_item_revisions` → `["projects", id, "item", code, "revisions"]`
  （历史版本内容经 include revisions 或详情载荷，见 api-contracts）；
- `get_relations` → `["projects", id, "item", code, "relations"]`；
- `get_impact` → `["projects", id, "impact", code]`。

## 交互

- 全部只读；跳转均为路由导航（可后退）；
- 版本切换不改变 URL（查看态），刷新回到当前版本。

## 状态与边界

- 编号不存在：错误态「条目不存在」（可能已被项目删除）；
- 无关联/无影响：面板分区内显示「无」而非隐藏（结构稳定，2026-09-03
  随区块迁移生效）；
- 仅 1 条修订：胶囊照常呈现 r1 当前（UI-031 同策略）。

## 测试要点

历史版本快照与 content_snapshot 一致（BR-004 只读）；关联上下游方向
正确；影响清单与 get_impact 一致；superseded 条目的替代者跳转；
「与上一版对比」开关四态：关（快照全文）/开（与上一版 diff）/最旧版
禁用/当前版开 = 最新修订与上一版对比；diffOn 跨修订切换保持、刷新
复位；提示条已废除（回到当前 = 点时间线当前版）。
