## 骨架示意

```text
根层级（/projects）              进入层级（/projects/:id/*）
┌──┬──────────────┬──────────  ┌──┬──────────────┬──────────
│☰ │ 总览          │ 内容区     │☰ │ ← 返回列表    │ 内容区
│◎ │──────────────│ （项目     │  │──────────────│ （项目
│  │ 项目          │  列表页）  │  │ relay-harbor │  概览页）
│  │  relay-harbor │           │  │   ○ 项目概览 │
│  │  zhsppy       │           │  │   ○ 项目统计 │
│⚙ │               │           │  │ 需求          │
└──┴──────────────┴──────────  │  │   ○ FR 功能  │
 ↑第一层(双态:   ↑第二层(停靠   │  │   ○ …（13 类型）
 ☰切纯图标/标签,  常驻,进入式)   │  │   ○ 任务     │
 设置钉底)                      │⚙ │              │
                                └──┴──────────────┴──────────

```
