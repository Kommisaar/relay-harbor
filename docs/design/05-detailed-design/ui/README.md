## 全局约束（继承，不因 UI 设计改变）

- UI 零业务写命令（CON-009、ADR-006）：全部页面只读，设置读写是唯一
  持久化写操作；
- 数据获取全部经 `api/` invoke，query key 以 `["projects", projectId, ...]`
  开头，事件失效 + refetchOnWindowFocus 兜底；
- 无编辑器、无 dnd 依赖（ADR-007）。
