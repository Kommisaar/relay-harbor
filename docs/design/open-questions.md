# 开放问题

## OQ-001 数据事实来源与条目粒度

- 状态：已解决
- 来源阶段：00-overview
- 影响：需求编辑方式、领域模型、存储设计、MCP 契约、导入导出和 Git 审查流程
- 是否阻塞：是
- 最晚决策点：确认 00 项目概览前
- 当前候选：
  - 数据库作为唯一运行时事实来源，条目使用结构化元数据加 Markdown 正文，Markdown/JSON 仅作为确定性快照（当前建议）；
  - Markdown 作为事实来源，数据库只做索引和缓存；
  - 数据库与 Markdown 双向可编辑，但需要复杂的冲突解决机制，不建议首期采用。
- 结论：采用候选一（2026-08-27 用户确认）：数据库为唯一运行时事实来源，条目为结构化元数据加 Markdown 正文；导出 Markdown/JSON 仅为确定性快照。
