# 风险

> 编号自 00 概览"主要风险"与 04 README"风险"整理而来（原文字保留在
> 各自文档，此处为可追踪清单）。

## RISK-001 业务写入唯一依赖应用存活

- 状态：已缓解（降低）
- 触发条件：Agent 写入时应用未运行或崩溃
- 影响：全部管理操作不可用
- 可能性：中（常态关机后首调）
- 关联：FR-011、CMP-007/008、UC-009
- 应对：降低
- 具体措施：托盘常驻默认隐藏；bridge 自动拉起（15 秒就绪）；错误明确
  返回不静默
- 验证信号：SEQ-002 三条恢复路径测试通过
- 剩余风险：拉起超时（应用损坏/安装异常）时需人工介入

## RISK-002 Plugin / 应用 / Schema / MCP 协议版本漂移

- 状态：已缓解（降低）
- 触发条件：任一组件单独升级
- 影响：Agent 通道不可用或行为不一致
- 可能性：中
- 关联：FR-001、NFR-006、ADR-004
- 应对：降低
- 具体措施：连接时版本握手，不兼容明确报错（ERR_VERSION_MISMATCH）；
  迁移只向前 + 降级检测
- 验证信号：握手不匹配路径测试；历史版本库迁移矩阵
- 剩余风险：极旧 Plugin 需手动升级（可接受）

## RISK-003 单一 SQLite 库损坏影响全部项目

- 状态：已缓解（降低）
- 触发条件：磁盘故障、进程异常
- 影响：全项目数据不可用
- 可能性：低
- 关联：ADR-003、NFR-001/004
- 应对：降低
- 具体措施：WAL 一致性；VACUUM INTO 备份纪律（文档化）；M2 确定性快照
- 验证信号：备份→恢复→一致性校验例程
- 剩余风险：两次备份之间的写入可能丢失（单用户桌面可接受）

## RISK-004 编码 Agent 越界（分层/依赖/只读边界被侵蚀）

- 状态：开放（有缓解计划，属持续风险）
- 触发条件：CI 防线缺失或被绕过
- 影响：架构边界名存实亡，规则双写漂移
- 可能性：中（Agent 生成代码的固有风险）
- 关联：CON-008/009、ADR-001/006/007
- 应对：降低
- 具体措施：CI 三件套（TS 最严 + 依赖白名单 + 目录边界 lint）+
  ipc 命令白名单断言 + domain 依赖黑名单检查——全部机器可校验
- 验证信号：CI 从脚手架第一commit起即存在且保持绿色
- 剩余风险：lint 规则本身的覆盖盲区（靠评审 test 要点清单补）

## RISK-005 本地 API 被本机其他进程滥用

- 状态：已缓解（降低）
- 触发条件：恶意/失控本地进程扫描回环端口
- 影响：越权写入设计数据
- 可能性：低
- 关联：NFR-005、ADR-004/005
- 应对：降低
- 具体措施：随机端口 + 每会话轮换令牌 + bridge.json 用户级权限；
  无效令牌拒绝测试
- 验证信号：端口扫描仅回环、令牌测试通过
- 剩余风险：同用户权限进程理论可读 bridge.json（单用户信任模型内接受）

## RISK-006 数据库取代 Markdown 后原生 Git 可读性下降

- 状态：已缓解（降低）
- 触发条件：用户习惯以 Git 历史审查设计演进
- 影响：审查体验退化
- 可能性：确定发生（形态使然）
- 关联：OQ-001、FR-014
- 应对：降低
- 具体措施：确定性 Markdown 导出（字节一致，可入 Git 比对）；不可变
  修订承载演进历史
- 验证信号：导出确定性测试；历史版本只读查看
- 剩余风险：导出为手动动作，非实时镜像（M2 快照改善）

## RISK-007 data-changed 事件丢失导致 UI 陈旧

- 状态：已接受
- 触发条件：发射与返回之间崩溃、监听晚注册
- 影响：面板显示旧数据直至刷新
- 可能性：低
- 关联：ADR-006
- 应对：接受
- 具体措施：refetchOnWindowFocus 兜底；事件尽力送达不持久化
- 验证信号：无需专门验证（行为已定义）
- 剩余风险：秒级陈旧窗口，产品可接受

## RISK-008 搜索 LIKE 在规模上界不达标

- 状态：开放（调查，含既定升级路径）
- 触发条件：条目/正文规模接近或超过 NFR-002 上界
- 影响：搜索超 1 秒
- 可能性：低（万级 LIKE 实测通常远低于 1s）
- 关联：NFR-002、FR-012、data-model
- 应对：调查
- 具体措施：规模数据计时测试给出实测值；不达标即按预埋路径升级 FTS5
- 验证信号：NFR-002 计时测试
- 剩余风险：无（路径明确）
